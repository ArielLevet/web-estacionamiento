# Estacionamiento Newbery

Sitio web de Estacionamiento Newbery, en Rosario, Santa Fe.

## Desarrollo

Sitio estático construido con HTML, CSS y JavaScript, sin frameworks ni proceso de compilación.

Para verlo localmente, abrir `index.html` en el navegador o usar Live Server en VS Code.

## Archivos principales

- `index.html`: estructura y contenido.
- `site-config.js`: configuración del sitio.
- `assets/`: imágenes y otros recursos.
